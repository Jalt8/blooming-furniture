## 📐 Technical Specifications

### Image Formats:
- **Preferred**: `.webp` (best performance)
- **Acceptable**: `.jpg` (for photos), `.png` (for graphics with transparency)
- **Avoid**: `.bmp`, `.gif` (for photos)

### Optimization:
- All images should be optimized/compressed before upload
- Target: < 200KB for thumbnails, < 500KB for full images
- Use tools like TinyPNG, Squoosh, or ImageOptim

### File Naming:
- Use lowercase
- Use hyphens (not underscores or spaces)
- Be descriptive: `antique-chair-restoration-before.jpg` not `img1.jpg`

---

## 📸 Photography Tips

1. **Lighting**: Natural light is best. Photograph near windows or outdoors.
2. **Background**: Clean, uncluttered backgrounds. White or wood tones work well.
3. **Angles**:
   - For furniture: 45-degree angle showing depth
   - For details: Straight-on macro shots
   - For heroes: Eye-level, slightly above
4. **Consistency**: Use similar lighting and backgrounds for before/after pairs
5. **Context**: Include hands, tools, or setting to add human element
